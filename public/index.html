Panduan Pemasangan

Gunakan dalam 1 Menit

Pilih klien AI favorit Anda dan salin konfigurasi yang telah disediakan.

Tambahkan ke file claude_desktop_config.json: 
{
  "mcpServers": {
    "satu-data-aceh": {
      "url": "https://www.mcpsatudataaceh.web.id/sse"
    }
  }
}
Tambahkan pada .cursor/mcp.json atau Settings > MCP: 
{
  "mcpServers": {
    "satu-data-aceh": {
      "url": "https://www.mcpsatudataaceh.web.id/sse"
    }
  }
}

Untuk akun ChatGPT yang memiliki fitur Developer Mode / Connectors:

  1. Buka menu Settings → Connectors / MCP.
  2. Klik tombol Add New MCP Server.
  3. Pilih tipe transport Server-Sent Events (SSE).
  4. Masukkan Server URL di bawah ini:
https://www.mcpsatudataaceh.web.id/sse
Konfigurasi via MCP Extension atau GitHub Copilot: 
{
  "name": "satu-data-aceh",
  "url": "https://www.mcpsatudataaceh.web.id/sse",
  "type": "sse"
}
