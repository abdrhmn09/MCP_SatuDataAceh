Hubungkan asisten AI.
Untuk ChatGPT Web dan klien OAuth, gunakan URL MCP berikut dan login saat diminta. Token manual tersedia untuk klien yang mendukung header Bearer.
OAuth otomatis
Tambahkan URL endpoint ke pengaturan MCP aplikasi AI. Pilih OAuth, masuk ke akun ini, lalu periksa dan setujui izin. Tidak perlu menyalin API key BPS atau token manual.
Dukungan koneksi bergantung pada aplikasi dan pengaturan workspace Anda. Server harus mengaktifkan transport endpoint yang dipilih.
Authorization: Bearer TOKEN_MCP_ANDA
Pada SSE, header diperlukan saat GET /sse dan POST /messages/. URL menggunakan domain utama layanan agar identitas OAuth konsisten.
Untuk OAuth, kosongkan client ID/secret jika klien mendukung discovery dan registrasi otomatis. Scope layanan ini adalah data:read. Kelola atau cabut izin di Aplikasi terhubung.
