02 / Delapan tools, satu koneksi
Dari penemuan hingga pemeriksaan.
Dokumentasi sumber BPS ↗
bps_endpoints
Temukan seluruh operasi, kategori, dan skema parameter API BPS. Dapat dijelajahi tanpa key.
bps_request
Ambil data dan metadata melalui operasi resmi. Domain dan filter mengikuti skema masing-masing operasi.
bps_check_key
Periksa apakah credential koneksi diterima oleh layanan BPS atau SDGs.
search · cari_katalog_data
Temukan dataset Portal Satu Data Aceh, filter wilayah/produsen, dan jelajahi halaman hasil.
fetch · baca_isi_csv
Baca observasi dan sumber dataset, dengan tahun data yang dipisahkan dari tanggal publikasi.
bandingkan_data
Tinjau dua sumber untuk indikator yang didukung. Perbedaan konsep atau satuan tidak dipaksakan menjadi perbandingan angka.


03 / Bawa ke alur kerja Anda
Hubungkan, lalu mulai eksplorasi.
Python harus dijalankan dengan MCP_TRANSPORT yang sesuai. Worker menggunakan /mcp. Reverse proxy perlu meneruskan /api/bps dan endpoint transport.
Daftar/login → simpan key BPS → buat token MCP → pasang token di klien AI. Token MCP berbeda dari API key BPS. Jangan memasukkan keduanya ke prompt AI atau URL.
Authorization: Bearer YOUR_MCP_ACCESS_TOKEN
Setel token MCP di header koneksi klien AI. Pada SSE, kirim saat membuka /sse dan POST /messages/. Setelah token dicabut atau kedaluwarsa, koneksi harus dibuat ulang dengan token baru. Klien harus mendukung Bearer manual; ini bukan alur OAuth otomatis.
