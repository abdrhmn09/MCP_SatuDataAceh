Belum disimpan
Belum ada key untuk layanan ini.
Spasi di awal/akhir dihapus otomatis. Jangan tempel URL, “Bearer”, atau “Authorization”. Key tidak ditampilkan kembali setelah disimpan. BPS dan SDGs Access memakai credential terpisah; pilih SDGs hanya untuk operasi berlabel SDGs Access.
Key dienkripsi AES-256-GCM. Menghapus key akan menghentikan akses BPS, tetapi tidak menghapus akun Anda.
Hapus key layanan ini? Simpan penggantinya agar akses BPS dapat digunakan lagi.

Dokumentasi VS Code

  

  

    Server lokal (STDIO) untuk Claude Desktop dan Antigravity
    
Siapkan Python 3.11+. Dari direktori repositori, buat lingkungan virtual dan instal proyek.

    
python3 -m venv .venv
.venv/bin/python -m pip install -e .

    
Pada Windows, gunakan py -3 dan Python di .venv/Scripts/python.exe. Simpan BPS_API_KEY dalam file .env pribadi di direktori proyek jika memakai BPS.

    
Masukkan konfigurasi ini ke claude_desktop_config.json atau mcp_config.json di Antigravity. Sesuaikan path absolut Python, lalu muat ulang aplikasi.

    
{
  "mcpServers": {
    "satu-data-aceh-local": {
      "command": "/path/ke/MCP_SatuDataAceh/.venv/bin/python",
      "args": ["-m", "src.main"],
      "env": {"MCP_TRANSPORT": "stdio"}
    }
  }
}

    
Untuk VS Code, pakai servers dan tambahkan "type": "stdio" pada entri server.

  

  
Uji koneksi
Minta aplikasi mencari dataset inflasi Aceh dengan tool search dan menampilkan ID serta tautannya. Untuk BPS, jalankan bps_request dengan operasi listDomains dan parameter {"type":"prov"}. Hasilnya mencakup domain Aceh 1100.




Memahami hasil pencarian dan kualitas data
Gunakan search → fetch untuk dataset portal dan bps_endpoints → bps_request untuk BPS. Filter wilayah pada search hanya memeriksa metadata katalog; lihat cakupan baris di fetch untuk memastikan wilayah. Nilai kosong pada JSON adalah null dan pada tabel ditampilkan sebagai —. Batas preview 50 baris bukan seluruh dataset.
bandingkan_data adalah audit terbatas, bukan pemilih sumber utama. Tahun terakhir yang berhasil dibaca tidak menjamin rilis terbaru. cari_katalog_data dan baca_isi_csv tetap tersedia untuk klien lama; alur baru dianjurkan memakai search/fetch agar memperoleh data terstruktur.
