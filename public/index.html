    OpenCode
    
Tambahkan konfigurasi berikut di opencode.json, lalu jalankan opencode mcp auth satu-data-aceh.

    
{
  "mcp": {
    "satu-data-aceh": {
      "type": "remote",
      "url": "https://www.mcpsatudataaceh.web.id/mcp",
      "oauth": {"scope": "data:read"}
    }
  }
}

    
Setujui akses di peramban, lalu periksa koneksi dengan opencode mcp list.

  

  

    Pengaturan lanjutan · Jalankan server lokal dengan STDIO
    
Pilih opsi ini jika ingin aplikasi AI menjalankan server sendiri di komputer Anda. Instal Python 3.11 atau lebih baru dan siapkan salinan repositori proyek.

    
Windows · PowerShell

    
Dari folder proyek, buat lingkungan virtual. Perintah pertama membuat .venv\Scripts\python.exe yang digunakan pada konfigurasi.

    
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .

    
macOS dan Linux · Terminal

    
python3 -m venv .venv
.venv/bin/python -m pip install -e .

    
Jika memakai data BPS, buat .env pribadi di folder proyek dan isi BPS_API_KEY. Untuk operasi SDGs Access, gunakan BPS_SDGS_TOKEN terpisah.

    
Gabungkan contoh berikut ke claude_desktop_config.json atau mcp_config.json Antigravity. Ganti command sesuai lokasi proyek, lalu muat ulang aplikasi.

    
{
  "mcpServers": {
    "satu-data-aceh-local": {
      "command": "C:/Projects/MCP_SatuDataAceh/.venv/Scripts/python.exe",
      "args": ["-m", "src.main"],
      "env": {"MCP_TRANSPORT": "stdio"}
    }
  }
}

    
Di macOS dan Linux, contoh command adalah /home/nama/MCP_SatuDataAceh/.venv/bin/python. Di VS Code, gunakan servers dan tambahkan "type": "stdio".

  

  
Uji koneksi
Minta aplikasi mencari dataset inflasi Aceh dengan tool search dan menampilkan ID serta tautannya. Untuk BPS, jalankan bps_request dengan operasi listDomains dan parameter {"type":"prov"}. Hasilnya mencakup domain Aceh 1100.




Memahami hasil pencarian dan kualitas data
Gunakan search → fetch untuk dataset portal dan bps_endpoints → bps_request untuk BPS. Filter wilayah pada search hanya memeriksa metadata katalog; lihat cakupan baris di fetch untuk memastikan wilayah. Nilai kosong pada JSON adalah null dan pada tabel ditampilkan sebagai —. Batas preview 50 baris bukan seluruh dataset.
bandingkan_data adalah audit terbatas, bukan pemilih sumber utama. Tahun terakhir yang berhasil dibaca tidak menjamin rilis terbaru. cari_katalog_data dan baca_isi_csv tetap tersedia untuk klien lama; alur baru dianjurkan memakai search/fetch agar memperoleh data terstruktur.
